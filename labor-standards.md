
# Labor Standards

## Purpose

This document defines the standard labor assumptions used for cabinet estimating, production planning, scheduling, and future automation.

These standards are intended to serve as the baseline labor model for all cabinet projects unless overridden by project-specific requirements.

Actual labor times should be tracked separately and used to refine these standards over time.

---

# General Rules

## Labor Categories

Labor is separated into the following categories:

| Category            | Description                                    |
| ------------------- | ---------------------------------------------- |
| Design              | Layout, revisions, renderings, CNC preparation |
| Material Processing | Sheet breakdown, CNC cutting, edge banding     |
| Assembly            | Cabinet assembly, drawer assembly, hardware    |
| Finishing           | Sanding, prep, priming, painting               |
| Installation        | Delivery, installation, trim, touch-up         |

---

## General Assumptions

Unless otherwise specified, the following assumptions apply:

* Frameless cabinet construction
* CNC cut components
* Standard plywood construction
* Standard shaker style fronts
* Soft close hinges and slides
* Standard hardware installation
* Normal residential installation conditions
* No plumbing or electrical modifications
* No specialty finishes
* No inset doors unless specified
* No highly figured or difficult hardwoods
* Components are cut using CNC workflow
* Standard cabinet dimensions

# Tracking Requirements

Actual labor hours should be tracked separately from estimated labor.

The following information should be recorded for every completed project:

* Estimated labor hours
* Actual labor hours
* Cabinet quantity
* Cabinet types
* Finish type
* Installation conditions
* Notes on delays or inefficiencies
