
# Estimating Standards

## Purpose

This document defines the estimating standards, assumptions, workflows, and pricing structure used for cabinet projects.

The purpose of this document is to create a repeatable estimating system that supports:

* Consistent quoting
* Future automation
* AI-assisted estimating
* Production planning
* Material forecasting
* Labor forecasting
* Revision tracking

This document should be treated as the primary source of truth for estimating rules unless project-specific overrides are documented separately.

---

# Estimating Philosophy

Estimates should be based on:

1. Repeatable cabinet standards
2. Standard labor assumptions
3. Material usage assumptions
4. Installation complexity
5. Finish complexity
6. Real-world tracked production data

Estimates should avoid guess-based pricing whenever possible.

---

# Core Estimating Structure

Projects are estimated using the following categories:

| Category     | Description                                  |
| ------------ | -------------------------------------------- |
| Materials    | Sheet goods, hardwood, hardware, consumables |
| Labor        | Shop labor and installation labor            |
| Finishing    | Paint, stain, prep, spray labor              |
| Delivery     | Transportation and loadout                   |
| Installation | Field labor and trim work                    |
| Design       | CAD, revisions, CNC programming              |
| Overhead     | Shop burden and indirect expenses            |
| Profit       | Final markup                                 |

# Standard Cabinet Assumptions

## Standard Base Cabinet

### Assumptions

* 24 inch depth
* 34.5 inch height
* Frameless construction
* CNC cut components
* Standard shaker fronts
* Soft close hardware
* Plywood construction

### Includes

* Cabinet box
* Adjustable shelving
* Standard hardware
* Drawer slides
* Hinges

### Excludes

* Installation
* Countertops
* Plumbing
* Electrical work
* Painting unless specified
* Crown molding
* Specialty inserts

---

## Standard Upper Cabinet

### Assumptions

* 12 inch depth
* Standard wall cabinet height
* Frameless construction
* CNC cut components
* Standard shaker fronts

### Includes

* Cabinet box
* Shelving
* Hinges
* Hardware

### Excludes

* Installation
* Crown molding

* Lighting

## Standard Pantry Cabinet

# Material Estimating Standards

## Sheet Goods

Material calculations should include:

* Cabinet parts
* Waste allowance
* Grain direction requirements
* Replacement risk
* Defect allowance

### Standard Waste Factors

| Material Type      | Waste Allowance |
| ------------------ | --------------: |
| Plywood            |             15% |
| Hardwood           |             20% |
| Painted Components |             10% |
| High-End Veneer    |             25% |

---

# Hardware Standards

## Standard Hardware Assumptions

Unless specified otherwise:

* Soft close hinges
* Soft close drawer slides
* Standard pulls/handles
* Adjustable shelves
* Shelf pins included

---

# Finish Standards

## Standard Painted Finish

Includes:

* Sanding
* Primer
* Paint application
* Final touch-up

Does not include:

* Specialty distressing
* High gloss finishes
* Color matching services

---

# Installation Standards

## Standard Installation Conditions

Standard installation assumes:

* Accessible residential jobsite
* Level floors within normal tolerance
* Standard wall conditions
* Clear access for material movement
* No major site modifications

---

# Complexity Adjustments

The following conditions should increase estimated labor and/or pricing.

| Condition                     | Recommended Multiplier |
| ----------------------------- | ---------------------: |
| Painted Finish                |                   1.25 |
| Inset Doors                   |                   1.50 |
| Custom Trim                   |                   1.35 |
| Curved Components             |                   1.75 |
| No CNC Workflow               |                   1.40 |
| High-End Hardwood             |                   1.15 |
| Difficult Installation Access |                   1.20 |
| Irregular Walls/Floors        |                   1.20 |
| Premium Hardware              |                   1.10 |

---

# Estimating Workflow

## Recommended Estimating Process

1. Gather customer requirements
2. Determine cabinet types and quantities
3. Apply cabinet standards
4. Estimate material usage
5. Estimate labor requirements
6. Apply finish adjustments
7. Apply installation adjustments
8. Add overhead and profit
9. Review estimate for completeness
10. Deliver customer quote

---

# Project Overrides

Any deviation from standard assumptions should be documented separately.

Examples include:

* Custom dimensions
* Specialty finishes
* Non-standard hardware
* Appliance integrations
* Site-specific challenges
* Customer-requested modifications

---

# Data Collection Requirements

The following information should be collected for completed projects:

* Material usage
* Actual labor hours
* Installation hours
* Finish hours
* Customer revisions
* Delays
* Profitability observations

This information should be used to refine future estimating standards.
