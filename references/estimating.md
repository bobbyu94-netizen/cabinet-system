# Estimating Standards

## Cost Categories

1. **Materials** — sheet goods, solid lumber, hardware
2. **Labor** — shop hours × rate (rate includes overhead and profit)
3. **Finishing** — paint, primer, stain, poly, consumables
4. **Delivery** — if applicable
5. **Installation** — if applicable
6. **Design** — drafting, rendering time

## Nine Standard Cabinet Types

| Type | Default Assumptions |
|---|---|
| Base cabinet | 34.5"H, 24"D, face frame, shaker doors |
| Upper cabinet | 30"H, 12"D, face frame, shaker doors |
| Pantry cabinet | 84–96"H, 24"D, face frame |
| Vanity cabinet | 34.5"H, 21"D, face frame |
| Drawer base | 34.5"H, 24"D, drawer stack (no doors) |
| Sink base | 34.5"H, 24"D, no shelf, open interior |
| Corner base | 36"W, 34.5"H, 24"D, lazy susan or blind |
| Wall cabinet | Same as upper cabinet |
| Tall cabinet | Same as pantry |

| Condition | Multiplier |
|---|---|
| Standard Construction | 1.00 |
| Painted Finish | 1.25 |
| Inset Doors | 1.50 |
| Custom Trim | 1.35 |
| High-End Hardwood | 1.15 |
| Highly Irregular Walls | 1.20 |
| Specialty Hardware | 1.15 |

## Labor Rate Note

The $65/hr labor rate already includes overhead and profit margin. Do NOT add overhead or profit as separate line items — doing so would double-count. The rate breaks down approximately as $35/hr labor + $30/hr business margin.

## Estimating Process (9 steps)

1. Capture customer requirements
2. Identify cabinet types and quantities
3. Apply standard dimensions
4. Calculate material quantities + waste
5. Price materials from price table
6. Estimate labor hours per cabinet type
7. Apply complexity multipliers
8. Add consumables (13% of material subtotal)
9. Deliver quote with line-item breakdown

## Quote Output Format

Present quotes with:
- Line item per cabinet (type, size, qty, unit price, extended)
- Material subtotal
- Labor subtotal
- Consumables
- **Total**

Flag any items with low-confidence pricing for manual review before sending to customer.
