## Hardware Rules

- Doors: 1 pair hinges per door (2 hinges), 1 pull per door
- Drawers: 1 pair undermount slides per drawer, 1 pull per drawer
- Shelves: 4 shelf pins per shelf location
- Standard base cabinet with 2 doors: 4 hinges, 2 pulls, 4 shelf pins

## Consumables
Add 13% of material subtotal for consumables (glue, screws, sandpaper, tape, finish supplies).

## Finish Materials (per cabinet, painted)
- Primer: 0.25 gal per cabinet (2 coats)
- Paint: 0.25 gal per cabinet (2 coats minimum)
- Caulk: 1 tube per 6 cabinets

## Poplar Board Selection Rules

- **Available widths:** 1x8 and 1x10 only — no narrower boards
- **Planning widths:** 1x10 = **9.0"**, 1x8 = **7.0"** (actual boards vary; use conservative planning width to avoid mid-job shortages)
- **Preference:** Always try 1x10 first. It yields more parts per board and reduces cross-cuts
- **No mixing:** Once a board width is chosen for a job, use only that width for all poplar on that job
- **Decision logic:** If the widest part needing a clean face fits on a 1x10 without excessive waste, use 1x10. If the layout is dramatically more efficient on 1x8 (e.g., all parts are ≤3.5" wide), use 1x8 instead — but commit to it for the whole job
- **Pricing unit:** Per linear foot. 1x8 = $5.34/LF, 1x10 = $8.57/LF
- **Board lengths in store:** 8ft, 10ft, 12ft available. Default to 10ft boards for planning
- **Quoting:** Calculate total LF needed (with waste), then determine board count using 10ft default. Show: total LF × rate = material cost
- **Cut plan:** Always show which board width was chosen, total LF purchased, board lengths selected, and why

## Poplar Rip Yield (How to Calculate LF of Board Needed)

Poplar parts are ripped from full-width boards. Do not treat each part as requiring its own linear foot — calculate how many parts fit across the board face, then determine board LF needed.

**Rip yield from 1x10 (9.0" planning width, 1/8" kerf per rip):**

| Part Type | Rip Width | Parts per LF of Board |
| --------- | --------- | --------------------: |
| Face frame stiles/rails | 1.5" | 5 |
| Door rails/stiles | 3.0" | 2 |
| Drawer front frame | 3.0" | 2 |

*Verification: 5 × 1.5" + 4 kerfs × 0.125" = 8.0" ≤ 9.0" ✓ | 3 × 1.5" + 2 × 0.125" = 4.75" but 6th piece fails: 6 × 1.5 + 5 × 0.125 = 9.625" > 9.0" ✗*
*3.0" verification: 2 × 3.0" + 1 kerf × 0.125" = 6.125" ≤ 9.0" ✓ | 3rd piece fails: 3 × 3.0 + 2 × 0.125 = 9.25" > 9.0" ✗*

**Rip yield from 1x8 (7.0" planning width, 1/8" kerf per rip):**

| Part Type | Rip Width | Parts per LF of Board |
| --------- | --------- | --------------------: |
| Face frame stiles/rails | 1.5" | 4 |
| Door rails/stiles | 3.0" | 2 |
| Drawer front frame | 3.0" | 2 |

*1x8 verification: 4 × 1.5" + 3 × 0.125" = 6.375" ≤ 7.0" ✓ | 2 × 3.0" + 1 × 0.125" = 6.125" ≤ 7.0" ✓*

**Calculation method:**

1. List all poplar parts with their lengths and rip widths
2. Group by rip width (1.5" face frame vs. 3.0" door/drawer)
3. For each group: sum total linear inches needed
4. Divide by parts-per-LF for the chosen board width → LF of board required per group
5. Sum all groups → total raw LF
6. Apply 15% waste factor → purchase LF
7. Convert to board count using 10ft default board length

**Example — 24" upper cabinet, 1x10 stock:**

Face frame parts (1.5" rip, 5 per LF):
- 2 stiles × 30" = 60"
- 2 rails × 21" = 42"
- Total: 102" ÷ 5 = 20.4" = 1.70 LF of board

Door parts (3.0" rip, 2 per LF), 2 doors at 10-15/16"W × 28"H:
- 4 stiles × 28.0" = 112"
- 4 rails × 5.6875" = 22.75"
- Total: 134.75" ÷ 2 = 67.4" = 5.62 LF of board

Raw total: 1.70 + 5.62 = 7.32 LF × 1.15 waste = **8.42 LF → 1 × 10ft board**
Cost: 8.42 LF × $8.57 = **$72.16**

## Limitations
These allowances do not account for grain direction matching, sheet nesting optimization, appliance openings or cutouts, specialty configurations, or defects. Always use actual cut list quantities when a cut list has been generated.
