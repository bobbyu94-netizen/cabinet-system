# Construction Standards

## Material Specifications

| Part | Material | Thickness |
|---|---|---|
| Cabinet box sides, top, bottom | Birch plywood | 3/4" |
| Cabinet back | Birch plywood | 3/4" |
| Shelves | Birch plywood | 3/4" |
| Drawer box sides, front, back | Birch plywood | 1/2" |
| Drawer box bottom | Birch plywood | 1/4" |
| Door panels | MDF | 1/4" |
| Face frames | Poplar | 3/4" |
| Door rails & stiles | Poplar | 3/4" |

Wet area override: use water-resistant plywood base, seal lower edges of all exposed wood. Door panels revert to 1/4" birch plywood (no MDF in wet areas).

## Face Frame Standards

- Stile width: 1.5"
- Rail width: 1.5"
- Overlay: 1/2" on all sides (face frame overhangs box by 1/2" on each exposed side)
- Joinery: pocket screws (hidden), Titebond 3 glue
- Frameless construction: non-standard, override only

## Door Standards (5-piece Shaker)

- Rail width: 3.0" (standard — most commonly changed item; all formulas use actual stile/rail width)
- Stile width: 3.0" (standard — most commonly changed item; all formulas use actual stile/rail width)
- Panel material: 1/4" MDF (1/4" birch in wet areas)
- Overlay: 1/2" on all exposed sides
- Center gap (double door): 1/8" total between doors (1/16" deducted per door at center)
- No gap on door height — height overlay goes edge to edge on top and bottom

### Door Part Cut Lengths

- **Stile blank** = full door height (stiles run the full height of the door)
- **Rail blank** = door width − (stile width × 2) + 0.75"
  - The 0.75" = 2 × 3/8" tenon (one tenon per end, inserted into the dado slot in the stile)
  - Example (3" stile, 10-15/16" door): 10.9375 − 6 + 0.75 = **5-11/16"**
- **Panel width** = door width − (stile width × 2) + (dado depth × 2)
- **Panel height** = door height − (rail width × 2) + (dado depth × 2)
  - Standard dado depth = 3/8" per side, so panel formula = door dimension − (rail or stile width × 2) + 0.75"
  - Panel sits loose in the dado — MDF panel has more play than the tenon

### Door Joinery

- Rails join to stiles via a **tenon inserted into a dado slot** — the same slot the panel floats in
- Tenon is visible from the top and bottom of the assembled door
- MDF panel floats freely in the slot (not glued); tenon is glued
- Dado depth: 3/8" per side

**Single door (cabinet width < 24"):**
- Door width = opening width + 1" (1/2" overlay each side)
- Door height = opening height + 1" (1/2" overlay top and bottom)

**Double door (cabinet width ≥ 24"):**
- Each door width = (opening width / 2) + 1/2" (hinge-side overlay) - 1/16" (center gap allowance)
- Door height = opening height + 1" (1/2" overlay top and bottom)

## Drawer Box Standards (Base Cabinet)

- Sides/front/back: 1/2" birch plywood
- Bottom: 1/4" birch plywood dadoed into sides
- Slide clearance: 1/2" per side (1" total) for undermount slides
- Drawer box width = opening width − 1"
- Drawer box depth (sides): **21"** — standard for undermount slides
- Drawer box height = 5/8 × opening height, max 6"
- Drawer box bottom: width = box width − 0.5", depth = 21" − 0.5" = **20.5"**
- Hardware: undermount soft-close slides, 22" (Blum or equivalent)

## Hardware Standards

- Hinges: concealed soft-close (Blum or equivalent), 2 per door standard, 3 for doors >40"
- Drawer slides: undermount soft-close
- Pulls/knobs: as specified by customer
- Shelf pins: standard 5mm, 4 per shelf location

## Joinery Priority

1. Pocket screws (preferred — hidden)
2. Brad nails + fill and sand
3. Titebond 3 glue on all joints

## Base Cabinet Construction Standards

**Applies to: base cabinets only. Do not apply these to uppers, pantries, or vanities.**

### Box

- Back: width = cabinet width − 2", height = **full cabinet height** (e.g., 34.5")
- Sides: depth = cabinet depth − 3/4" (face frame), height = full cabinet height
- Bottom: width = back width, depth = side depth − 3/4" (back panel) = cabinet depth − 1-1/2"
- Top: **two nailers, each 4" wide × back width** (front nailer and back nailer) — no full top panel
- Shelf: width = back width − 1/16" (adjustable — standard), depth = side depth − 2"
- Default shelf count: **1** per base cabinet
- Toe kick: **4"** recessed cutout at bottom front of sides — not a separate part

### Face Frame

- Stile height = back panel height − toe kick + 0.75"
  - The +0.75" brings the stile down to cover the bottom face of the bottom panel
  - Example (standard base): 34.5" − 4" + 0.75" = **31.25"**
- Rail length = cabinet width − (2 × stile width) = cabinet width − 3"
- Standard base with drawer: **3 rails** (top, drawer divider, bottom)

### Face Frame Openings (Base with Standard Drawer)

- Total opening space = stile height − (3 rails × 1.5") = 31.25" − 4.5" = **26.75"**
- Drawer face height: **6"** (standard for all base cabinets)
- Drawer opening = drawer face − 1" (1/2" overlay each side) = **5"**
- Door opening = total opening space − drawer opening = 26.75" − 5" = **21.75"**
- Door height = door opening + 1" overlay = **22.75"**

### Drawer Standards (Base Cabinet)

- Drawer face height: **6"** (standard — always)
- Drawer opening height: **5"** (face − 1" for 1/2" overlay each side)
- Drawer box width = opening width − 1" (1/2" slide clearance per side)
- Drawer box depth (sides): **21"** — standard for undermount slides
- Drawer box height = 5/8 × opening height (max 6")
- Drawer box bottom: width = box width − 0.5", depth = box depth (21") − 0.5" — the 0.5" per dimension accounts for the dado on each side
- Hardware: undermount soft-close slides, 22" (Blum or equivalent)

## Upper Cabinet Construction Standards

**Applies to: upper cabinets only. Do not apply base cabinet formulas here.**

### Face Frame Drives the Box

For upper cabinets, the face frame dimensions are established first. The box is built from those dimensions, starting with the back panel. Example: a 24" upper has a 24" × 30" face frame.

### Face Frame

- Stile height = cabinet height (no toe kick — stile runs full height, e.g., 30")
- Rail length = cabinet width − (2 × 1.5" stiles) = cabinet width − 3"
- 2 rails only: top and bottom (no drawer divider)
- Opening height = cabinet height − (2 rails × 1.5") = cabinet height − 3"
  - Example (30" upper): opening = 27", door height = 28"
- Door height = opening height + 1" (1/2" overlay top and bottom)

### Back Panel

The back panel is the anchor of the box — every other part references it.

- 1/4" reveal on top and both sides
- Back width = cabinet width − 2×(3/4" side + 1/4" reveal) = cabinet width − 2"
- Back height = cabinet height − 1/4" (1/4" reveal at top only; back runs flush to the bottom)
  - Example (30" upper): back height = 29-3/4"

### Box

- Sides: height = back panel height (sides match the back — not cabinet height)
- Sides: depth = cabinet depth − 3/4" (face frame)
- Top panel: **solid panel** (not nailers), width = back panel width, depth = cabinet depth − 3/4" (face frame) − 3/4" (back panel) = cabinet depth − 1-1/2"
- Bottom panel: width = back panel width, depth = cabinet depth − 3/4" (face frame) − 3/4" (back panel) = cabinet depth − 1-1/2"
- **All components (top, bottom, shelves) sit between the sides** — pocket screwed into place
- Shelves: width = back width − 1/16" (adjustable — standard), depth = side depth − 2"
- Default shelf count: **2** per upper cabinet
- No toe kick
- No drawer

## Toe Kick

- Standard toe kick height: **4"** (base cabinets and vanities only — not uppers or pantries)
- Toe kick is a **recessed cutout** at the bottom front of the cabinet sides — it is not a separate panel and is not subtracted from stile height directly (see Base Cabinet stile formula above)

## Part Listing Rules

- **Always list parts as individual rows, qty 1 each** — never group with qty > 1
- Example: Left Side (qty 1) and Right Side (qty 1) as separate rows — not "Side (qty 2)"
- This applies to every sheet: birch parts, poplar parts, drawer parts, door panels
- When the cut plan asks "how many" — show each piece as its own row

## Workflow & Cutting Sequence

- Plywood: track saw for breakdown → table saw for final dimensioning
- Poplar stock: 1x10 preferred, 1x8 minimum — never mix widths on a single job
- Planning width for 1x10: **9.0"** (actual boards vary; 9.0" is the conservative planning width to avoid mid-job shortages)
- Planning width for 1x8: **7.0"** (same conservative approach)
- Priority: durability → workflow efficiency → waste reduction → visual consistency

## Poplar Cut Workflow

1. **Survey all parts** — list every poplar part needed with width and length before making any cuts
2. **Crosscut to length first** — from whatever board or offcut you are working from, miter cut to the length of the part being made. Always start with the longest part
3. **Rip for width** — extract as many parts of the same width as possible from that section
4. **Kerf = 1/8" per rip** — deduct 0.125" from remaining width for every rip made
5. **Track offcuts** — after all rips from a section, any remaining width ≥ 1.5" is a usable offcut; record its width and length
6. **Scrap threshold** — any remaining width < 1.5" after a rip is scrap; do not track it
7. **Crosscut offcuts** — when using an offcut for a shorter part, crosscut it to the needed length first; the remaining length piece is also an offcut if ≥ 1.5" wide
8. **Best utilization** — at every decision point, evaluate all available material (remaining board length + all live offcuts) and choose the assignment that wastes the least
9. **Width check** — an offcut can only yield a part if: offcut width ≥ part width + 1/8" kerf

**Offcut states in the cut plan:**
- **Offcut** — ≥ 1.5" wide, no remaining use in this project; record dimensions only
- **Scrap** — < 1.5" wide; no value, not tracked

## Finishing

- Interior: clear coat
- Exterior: painted (default) or stained as specified
- Painted finish requires: primer + 2 coats paint, sand between coats
- All face frame and door surfaces must be sanded to 150 grit before finish
